# Security

Repo City runs entirely in the browser and makes no network calls at runtime other than loading its own files. `city:repo` runs **your repository's own tests** on your machine with Node's test runner, so only point it at code you trust, as you would with `npm test`.

To report a vulnerability, please use GitHub's private vulnerability reporting ("Report a vulnerability" under the Security tab of this repository) rather than a public issue. We will reply within a few days.
